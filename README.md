# 香蕉踩香蕉 · Banana Hop

一款電腦與手機都能玩的 Canvas 2.5D 香蕉生存遊戲。跳踩香蕉、閃開蕉皮，在水果混戰中撐過 120 秒。

使用原生 HTML、CSS、JavaScript 與 Web Audio；無執行期外部套件，也不需要建置步驟。完整遊戲與素材都在 `dist/`。

## 本機執行

需要 Python 3；檢查與測試需要 Node.js 22 以上（CI 使用 Node.js 24）。

```sh
cd ~/dev/github/banana-hop
python3 -m http.server 8893 --bind 127.0.0.1 --directory dist
```

開啟 <http://127.0.0.1:8893/>。也可使用 `npm start`，不需先執行 `npm install`。

同 Wi-Fi 手機試玩時，將 `--bind 127.0.0.1` 改為 `--bind 0.0.0.0`，以手機瀏覽器開啟電腦的區網 IP 與 8893 埠。

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD／方向鍵 | 左側虛擬搖桿 |
| 跳踩 | Space | 跳踩按鈕 |
| 無敵旋轉衝刺 | J | 衝刺按鈕 |
| 暫停／繼續 | P／Esc，或右上暫停鍵 | 右上暫停鍵 |

右上音量滑桿同時控制音樂與音效；拉到 0 即靜音，音符按鈕可恢復上次音量。

## 遊戲規則

- 存活 120 秒過關，玩家有 5 格紅香蕉生命。受到傷害後短暫無敵。
- 小香蕉只有綠色與黃色：綠色被踩後變黃，黃色再被踩就留下香蕉皮。自然生成頻率為原始正常設定的 75%，隨時間加快。
- 每段首踩集氣 0.2，後續連踩每次 0.1；能量上限一層。滿氣後可朝目前移動方向旋轉衝刺 1 秒，期間無敵。
- 地面香蕉皮不再按時間淡出。普通蕉皮被玩家或敵人踩中後消失並造成滑倒；滑倒本身不扣血，但期間撞到敵人仍會受傷。
- 第 10 秒起出現榴槤；不能踩，跳躍中也可能被撞到。大絕及氣功蕉皮可擊退榴槤。
- 第 20 秒起出現大深綠衝刺蕉；接近 viewport 邊緣時煞車 1 秒、停 2 秒。被踩或被大絕打中後分裂成兩隻綠小蕉。
- 第 30 秒起出現大紅蕉，以同期小兵平均速度的 1.5 倍尋找榴槤，抓起後旋轉投向玩家。被踩或被大絕命中後變成大深綠蕉。
- 第 17 秒起每 17 秒在 viewport 外生成香蕉串，盡量分散，按左、右、上、下輪替；18 秒未撿會消失，邊緣箭頭提示位置。
- 香蕉串只供玩家拾取，需著地或正在無敵衝刺，敵人不能吃。撿取後放出六片順時鐘向外擴散的氣功蕉皮，每輪對每個敵人造成一次傷害並向外擊退；榴槤只擊退。
- 剩 60 秒時倒數轉黃、音樂 1.2 倍節奏；剩 30 秒時轉紅、音樂 1.5 倍節奏、敵人移動與投擲榴槤飛行速度 1.5 倍；剩 10 秒時音樂 2 倍節奏並顯示大型倒數。
- 音樂以固定音符頻率重新合成各種節奏，保持音高不變。失焦或切換分頁自動暫停。
- 結束時凍結戰場並播放 2 秒黑白掃落動畫，結算存活時間、最大連踩、踩掉香蕉、擊敗總數、衝刺與香蕉串數。

成功對聯：歷盡千蕉百難／終成不敗蕉王。敗北對聯：天有不測風雲／蕉有旦夕禍福。

## 隱藏除錯選項

在主選單直接輸入 `banana`，即可顯示：

- 起點：正常開始，或從剩餘 62／32／12 秒開始。
- 無敵模式：開局後不會扣血，仍可滑倒、跳踩、集氣及過關。

設定在開始新局時套用。一般遊玩不會顯示此選單。

## 檢查與測試

```sh
npm run check
npm test
```

無套件依賴，不需安裝步驟。測試涵蓋碰撞、跳踩、能量、衝刺、敵人變形、蕉皮、香蕉串、音樂音高與節奏、倒數、除錯模式及完整 120 秒模擬。

## GitHub Pages

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) 會在推送至 `main`、對 `main` 開 Pull Request 或手動觸發時執行檢查與測試。只有 `main` 的推送或手動執行會部署，發佈內容僅包含 `dist/`。

將此儲存庫推送到 GitHub 後：

1. 在儲存庫 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。
2. 推送至 `main`，或在 Actions 手動執行 **Test and deploy GitHub Pages**。
3. 部署完成後，從 workflow 的 `github-pages` environment 取得網址。

所有遊戲資源使用相對路徑，可部署於 `https://<使用者>.github.io/<儲存庫名稱>/`，無需修改 base URL。

部署流程依照 [GitHub 官方靜態網站 workflow](https://github.com/actions/starter-workflows/blob/main/pages/static.yml) 配置。此專案不需要額外的部署 secret。

## 專案結構

```text
.github/workflows/pages.yml  檢查、測試與 Pages 部署
art/                        素材提示詞與參考預覽
 dist/                      可直接部署的完整遊戲
  assets/                   角色、敵人、道具及地板透明貼圖
  index.html                頁面與介面
  style.css                 版面與效果
  game.js                   遊戲及合成音樂／音效
 tests/game.test.cjs         Node.js 遊戲測試
```

貼圖來自使用者提供的素材與依參考圖生成的圖像；生成提示詞保存在 `art/`。音樂與音效由 Web Audio 合成，不需外部音檔。

手機開始遊戲後，戰場以 CSS 鋪滿網頁可視範圍，暫停與結算也維持滿版。主角與所有敵人（含榴槤）的貼圖與碰撞尺寸為桌面版的 0.7 倍，觸控操作、HUD、地板與地面道具維持可讀尺寸；適用直向、橫向與安全區域。

啟動時會顯示圖片載入過場與進度，七張角色／敵人／道具／背景貼圖完成下載及解碼、地板快取準備好之後才開放主選單與開始按鈕。失敗時可重試，未載入完成不會顯示舊向量角色或啟動遊戲。
