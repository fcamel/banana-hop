# 香蕉踩香蕉 · Banana Hop

一款電腦與手機都能玩的 Canvas 2.5D 香蕉生存遊戲。跳踩香蕉、閃開蕉皮，在水果混戰中撐過 120 秒，再擊敗腐蕉法師。

使用原生 HTML、CSS、JavaScript 與 Web Audio；無執行期外部套件，也不需要建置步驟。完整遊戲與素材都在 `dist/`。

## 本機執行

需要 Python 3；檢查與測試需要 Node.js 22 以上（CI 使用 Node.js 24）。

```sh
cd ~/dev/github/banana-hop
python3 -m http.server 8893 --bind 127.0.0.1 --directory dist
```

開啟 <http://127.0.0.1:8893/>。也可使用 `npm start`，不需先執行 `npm install`。

同 Wi-Fi 手機試玩時，將 `--bind 127.0.0.1` 改為 `--bind 0.0.0.0`，以手機瀏覽器開啟電腦的區網 IP 與 8893 埠。

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD／方向鍵 | 左側虛擬搖桿 |
| 跳踩 | Space | 跳踩按鈕 |
| 無敵旋轉衝刺 | J | 衝刺按鈕 |
| 暫停／繼續 | P／Esc，或右上暫停鍵 | 右上暫停鍵 |

右上音量滑桿同時控制音樂與音效；拉到 0 即靜音，音符按鈕可恢復上次音量。

## 遊戲規則

- 存活 120 秒後進入魔王戰，擊敗魔王才過關；玩家有 5 格紅香蕉生命。受到傷害後短暫無敵。
- 小香蕉只有綠色與黃色：綠色被踩後變黃，黃色再被踩就留下香蕉皮。自然生成頻率為原始正常設定的 75%，隨時間加快。
- 每段首踩集氣 0.2，後續連踩每次 0.1；能量上限一層。滿氣後可朝目前移動方向旋轉衝刺 1 秒，期間無敵。
- 地面香蕉皮不再按時間淡出。普通蕉皮被玩家或敵人踩中後消失並造成滑倒；滑倒本身不扣血。敵人滑倒／倒地期間不造成碰撞傷害，起身後恢復；大蕉滑行初速為主角與小兵的 60%，倒地時間同為 0.7 秒。玩家滑倒期間仍會被站立敵人、榴槤或鬼火打傷。
- 第 10 秒起出現榴槤；不能踩，跳躍中也可能被撞到。大絕及氣功蕉皮可擊退榴槤。
- 第 20 秒起出現大深綠衝刺蕉；接近 viewport 邊緣時煞車 1 秒、停 2 秒。被踩或被大絕打中後分裂成兩隻綠小蕉。
- 第 30 秒起出現大紅蕉，以同期小兵平均速度的 1.5 倍尋找榴槤，抓起後旋轉投向玩家。被踩或被大絕命中後變成大深綠蕉。
- 第 17 秒起每 17 秒在 viewport 外生成香蕉串，盡量分散，按左、右、上、下輪替；香蕉串不會按時間消失，最多保留最新兩串；第三串出現時移除最早未吃的一串，邊緣箭頭提示位置。
- 香蕉串只供玩家拾取，需著地、正在無敵衝刺或蕉皮衝浪，敵人不能吃；衝浪使用 55 單位拾取範圍，路徑判定包含結束及觸發魔王轉場的那一幀。撿取後放出六片順時鐘向外擴散的氣功蕉皮，每輪對每個敵人造成一次傷害並向外擊退；榴槤只擊退。
- 剩 60 秒時倒數轉黃、音樂 1.2 倍節奏；剩 30 秒時轉紅、音樂 1.5 倍節奏、敵人移動與投擲榴槤飛行速度 1.5 倍；剩 10 秒時音樂 2 倍節奏並顯示大型倒數。
- 音樂以固定音符頻率重新合成各種節奏，保持音高不變。失焦或切換分頁自動暫停。
- 結束時凍結戰場並播放 2 秒黑白掃落動畫，結算存活時間、最大連踩、踩掉香蕉、擊敗總數、衝刺與香蕉串數。

成功對聯：歷盡千蕉百難／終成不敗蕉王。敗北對聯：天有不測風雲／蕉有旦夕禍福。

## 隱藏除錯選項

在主選單直接輸入 `banana`，即可顯示：

- 起點：正常開始、從剩餘 62／32／12 秒開始，或直接魔王戰。
- 無敵模式：開局後不會扣血，仍可滑倒、跳踩、集氣及過關。

設定在開始新局時套用。一般遊玩不會顯示此選單。

## 檢查與測試

```sh
npm run check
npm test
```

無套件依賴，不需安裝步驟。測試涵蓋碰撞、跳踩、能量、衝刺、敵人變形、蕉皮、香蕉串、音樂音高與節奏、倒數、除錯模式及完整 120 秒模擬。

## GitHub Pages

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) 會在推送至 `main`、對 `main` 開 Pull Request 或手動觸發時執行檢查與測試。只有 `main` 的推送或手動執行會部署，發佈內容僅包含 `dist/`。

將此儲存庫推送到 GitHub 後：

1. 在儲存庫 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。
2. 推送至 `main`，或在 Actions 手動執行 **Test and deploy GitHub Pages**。
3. 部署完成後，從 workflow 的 `github-pages` environment 取得網址。

所有遊戲資源使用相對路徑，可部署於 `https://<使用者>.github.io/<儲存庫名稱>/`，無需修改 base URL。

部署流程依照 [GitHub 官方靜態網站 workflow](https://github.com/actions/starter-workflows/blob/main/pages/static.yml) 配置。此專案不需要額外的部署 secret。

## 專案結構

```text
.github/workflows/pages.yml  檢查、測試與 Pages 部署
art/                        素材提示詞與參考預覽
 dist/                      可直接部署的完整遊戲
  assets/                   角色、敵人、道具及地板透明貼圖
  index.html                頁面與介面
  style.css                 版面與效果
  game.js                   遊戲及合成音樂／音效
  boss.js                   魔王招式、十格生命、分身與專屬音樂
 tests/game.test.cjs         Node.js 遊戲測試
```

貼圖來自使用者提供的素材與依參考圖生成的圖像；生成提示詞保存在 `art/`。音樂與音效由 Web Audio 合成，不需外部音檔。

手機開始遊戲後，戰場以 CSS 鋪滿網頁可視範圍，暫停與結算也維持滿版。主角與所有敵人（含榴槤）的貼圖與碰撞尺寸為桌面版的 0.7 倍，觸控操作、HUD、地板與地面道具維持可讀尺寸；適用直向、橫向與安全區域。

啟動時會顯示圖片載入過場與進度，十張角色／敵人／魔王／道具／背景貼圖完成下載及解碼、地板快取準備好之後才開放主選單與開始按鈕。失敗時可重試，未載入完成不會顯示舊向量角色或啟動遊戲。

## 腐蕉大法師魔王戰

120 秒結束時先凍結全場：地上亮起綠色六芒星陣，魔王用 3 秒由法陣浮出；浮出後所有小兵轉為香蕉皮，魔王擺姿勢停 1 秒，再顯示「腐蕉大法師」大字 0.9 秒後恢復操作。轉場期間不受傷、不生成敵人、不消耗道具時間，暫停也會停住動畫。之後停止一般敵人自然生成。倒數消失，改顯示十根血紅香蕉（兩排）；戰鬥無時間上限，擊敗魔王才播放勝利曲與結算。

主選單可選「正常開始」或「直接魔王戰」，不需先開除錯模式。

- 魔王有十滴血；最後兩滴血都需先清掉分身，才能扣除本尊血量。每次命中後魔王無敵 4 秒、後退約 104 單位，施法會被打斷，硬直 0.65 秒後恢復攻擊。主角以站立姿勢向外彈飛 0.7 秒，不播放滑倒動畫；彈開期間短暫無敵、主角不閃爍，顯示「踩中！」與上彈箭頭；受傷無敵仍會閃爍。手機距離隨角色縮放。旋轉衝刺與蕉皮衝浪也能造成一次傷害，沿用魔王護罩與受擊無敵；命中後玩家繼續前進。
- 基本順序：蕉皮海 → 死蕉召喚 → 鬼火；7 血起偶爾瞬移到 viewport 另一側（0.3 秒黑影與效果線預告），6 血起偶爾施放鬼火護罩（蓄力 1 秒、維持 3 秒，以 8 簇放大且繞行的簡易火焰呈現、半徑擴大至 112 單位；碰到會受傷且不能踩）。
- 蕉皮海：舉杖 1 秒，放出三圈（8／12／16 片）向外滑行的香蕉皮；放射半徑隨 viewport 擴大，停止後留在地上，踩中才消失。
- 死蕉召喚：蓄力 3 秒，只消耗範圍內現存香蕉皮，最多 12 片各變為 1 隻黃色小蕉；空地不會憑空生兵。
- 鬼火：10 血每排 3 顆／1 排；9 血 4 顆／1 排；8 血 5 顆／2 排；7 血 6 顆／3 排；6 血以下最強版每排 7 顆、3 排連放 2 輪。排間隔最低 0.18 秒、輪間隔 0.35 秒、鬼火留場 2.6 秒。每次發射前固定蓄力 1 秒，以聚氣光球與聚攏粒子提示，不畫地面攻擊範圍；整次連發鎖定方向，發射角度最多四分之一圈。主角高度達 58 單位（普通跳躍頂點附近）可越過鬼火，起跳與落下時仍會受傷。
- 5 血：以 6 秒完成升空、0.3 秒空中定姿、蓄力收緊、地震蕉爆發、四方聚合與落地。玩家仍可移動、跳躍、撿道具及使用技能，雙方不會受傷；完成後恢復傷害，不清除輸入或中斷正在使用的技能。召喚區域依施法開始時的 viewport 固定；24 片蕉皮分到四象限，各取 3 片變成大深綠蕉。場景淡淡壓暗，保留角色亮度；法杖聚光搭配升調蓄力音、釋放重音與短震動，四個召喚點同步閃光、讓大蕉浮現。不顯示資訊牌、文字或進度條。
- 4 血：先發同樣的地震蕉補充材料，0.9 秒後開始聚合、1.2 秒完成大綠蕉召喚；不暫停世界、不重播升空過場。供召喚的飛行蕉皮及聚合中的蕉皮不會被踩掉或被別的招式重複消耗。
- 3、2 血：各在 viewport 左右中點出現大紅蕉 1 隻，每隻旁邊附帶 2 顆榴槤。
- 2 血起：本尊約每 7 秒可召喚一次分身（蓄力 1 秒），每次 1 個；1 血改為每次 2 個，含本尊最多 4 體。1 血保留 3 秒分身過場。分身使用同等強度的鬼火、防護罩、蕉皮海與死蕉召喚，只有本尊能再召喚分身。分身踩中 1 次消滅；剩 2 滴或 1 滴血時，本尊被踩或被大招打中，只要仍有分身，就由隨機存活分身繼承且不扣血；先清掉分身才能再扣本尊血，血量歸零才勝利。魔王身上不顯示本尊或分身文字。
- 專屬 BGM 為 128 BPM、30 秒無縫循環的幽靈放克（切分低音貝斯、突出管風琴、陰森和聲、鐘聲與重鼓）。魔王戰固定原速，不套用生存倒數加速；最後一格血只加入鼓點與鐘聲層次，保持音高與速度。
- 除錯選單可「直接魔王戰」，會準備蕉皮供測試，亦可搭配無敵模式。

魔王行為與專屬音樂在 `dist/boss.js`。`dist/assets/boss-necromancer-v1.png` 以使用者參考圖透過內建 imagegen 去背製作，提示詞保存於 `art/boss-necromancer-v1-prompt.txt`，已納入啟動載入檢查。

## 本機效能優化

- 敵人分離碰撞採 96 單位的動態格子，僅查附近九格；維持原本的碰撞順序、推開距離與衝撞規則，縮放比例每輪只算一次。
- 畫面外敵人、香蕉皮、香蕉串與特效略過繪製，物件仍保留並正常更新。
- 載入時預先合成四種速度的生存音樂與兩種魔王配器；播放時只建立並快取對應 AudioBuffer，保留原有音高。
- 載入時建立適合 DPR 2 的縮圖快取，敵人有普通／大型兩組，支援旋轉、左右翻面與角色狀態；原始美術檔不變。


## 蕉皮衝浪

- 撿到蕉皮滑板可攜帶最多 3 個；K 鍵、滑鼠點擊或手機右側衝浪按鈕消耗 1 個，不耗集氣，滑倒時也能使用。
- 衝浪 2 秒，可用移動鍵／搖桿帶慣性轉向，全程無敵；吃掉沿途蕉皮，每片增加 0.2 秒，單次最多 4 秒。顯示持續倒扣的衝浪氣量表，吸收蕉皮時氣條回補發光，並有擴散光環、粒子、加秒數字與音效回饋。結束後有短暫無敵及防滑。
- 撞擊敵人造成一次傷害並推開，同一目標每次使用最多命中一次；魔王護罩與受擊無敵照常有效。保留召喚儀式中的香蕉皮。
- 生存階段第 15、45、75、105 秒固定補給，每擊敗 3 隻大深綠蕉掉落一個；魔王剩 7、4、2 血時補給一個。道具不會過期，敵人不能撿，滿 3 個時留在地上，畫面外有青綠色箭頭。
- 新貼圖 `dist/assets/hero-surf-v1.png`、`dist/assets/surfboard-v1.png` 由內建 imagegen 依現有主角參考圖生成，保留透明背景；提示詞存於 `art/` 同名檔。圖片均納入啟動載入與縮圖快取。衝浪邏輯在 `dist/surf.js`。
